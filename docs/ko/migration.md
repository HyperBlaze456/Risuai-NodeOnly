# RisuAI 데이터 이전 가이드

기존 RisuAI(웹 리스, 로컬 리스)에서 PocketRisu로 데이터를 이전하는 방법은 네 가지입니다. 출발 환경과 데이터 규모에 따라 선택합니다.

- [1. RisuAI 계정에서 가져오기](#1-risuai-계정에서-가져오기) — 웹 리스 계정 연동. 서버가 계정 데이터를 직접 받음.
- [2. 로컬 백업 파일(.bin) 이전](#2-로컬-백업-파일bin-이전) — 모든 환경에서 동작. 가장 일반적인 방법.
- [3. Save 폴더 zip 업로드](#3-save-폴더-zip-업로드) — 로컬 리스, 소규모 데이터.
- [4. Save 폴더 직접 복사](#4-save-폴더-직접-복사) — 로컬 리스, 대규모 데이터.


## 시작하기 전에

> ⚠️ 이전 작업 전에 **기존 데이터를 백업**해두세요. 기존 RisuAI의 설정 > 백업에서 `.bin` 파일로 내보낼 수 있습니다.


---

## 1. RisuAI 계정에서 가져오기

웹 리스(risuai.xyz) 계정에 저장된 데이터를 PocketRisu 서버가 RisuAI에서 직접 받아 오는 방식입니다. 계정의 캐릭터, 채팅, 설정, 이미지를 옮깁니다.

1. **웹 리스** (계정 연동을 쓰고 있지 않았다면): 설정 > 계정 & 파일에서 로그인한 뒤 "계정에 데이터 저장"을 켭니다. 선택창이 뜨면 "계정에 데이터 현재 덮어쓰기"를 고르고, 확인 입력란에 `RISUAI`를 입력하면 지금 데이터가 계정으로 올라갑니다.
2. **PocketRisu**: 설정 > 데이터 이전 > "RisuAI 계정에서 가져오기"에서 RisuAI 이용약관에 동의하고 로그인합니다.
3. 가져올 캐릭터, 채팅, 이미지 수와 예상 시간을 확인한 뒤 "가져오기 시작"을 누릅니다.
4. 끝날 때까지 PocketRisu에는 가져오기 화면만 보입니다. 끝나면 데이터가 바뀌고 자동으로 새로고침됩니다.

> ⚠️ 가져오기는 PocketRisu의 **지금 데이터를 계정 데이터로 모두 바꿉니다** (합치지 않습니다). 남겨야 할 데이터가 있다면 먼저 백업하세요.

- RisuAI 서버에 부담을 주지 않도록 1초에 하나씩 받습니다. 이미지가 많으면 몇 시간 걸릴 수 있습니다.
- 서버가 다시 시작되거나 RisuAI 로그인이 만료되면, 다시 로그인했을 때 남은 것만 이어서 받습니다.
- 채팅에 넣은 이미지(인레이)는 브라우저에만 저장되어 있어 가져오지 않습니다.
- RisuAI 계정 저장 공간에는 용량 한도가 있습니다.


---

## 2. 로컬 백업 파일(.bin) 이전

기존 RisuAI에서 내보낸 `.bin` 백업 파일을 PocketRisu에서 불러오는 방식입니다. 출발 환경(웹/Tauri/Capacitor/로컬)에 무관하게 동작합니다.

1. **기존 RisuAI**: 설정 > 백업 > "로컬 백업 저장"으로 `.bin` 파일 내보내기
2. **PocketRisu**: 설정 > 데이터 이전 > "원본 리스 로컬 백업 불러오기"로 `.bin` 파일 가져오기

> ⚠️ **일시적인 문제 (2026년 10월 기준)**: 웹 리스(risuai.xyz) 최신 버전에서는 계정 로그인 여부와 관계없이 "로컬 백업 저장" 파일의 데이터베이스가 암호화됩니다. PocketRisu에서 불러오면 "암호화된 백업" 안내와 함께 거부됩니다(원본 데스크톱 앱이나 노드리스에서 만든 백업은 해당 없음). 원본 RisuAI에 수정을 요청해 둔 문제입니다([kwaroran/Risuai#1681](https://github.com/kwaroran/Risuai/issues/1681)). 해결될 때까지는 웹 리스의 계정 연동을 거쳐 [1. RisuAI 계정에서 가져오기](#1-risuai-계정에서-가져오기)로 옮겨 주세요.
>
> 원래 웹 리스에서 계정 연동("계정에 데이터 저장")을 쓰고 있었다면 백업은 이 문제와 상관없이 암호화되어 있습니다. 이 경우에도 1번 방법을 쓰세요.



---

## 3. Save 폴더 zip 업로드

기존에 로컬 리스(Node 서버 버전)를 사용 중이었다면, `save` 폴더를 zip으로 압축해 업로드할 수 있습니다.

1. 기존 RisuAI 프로젝트의 `save` 폴더를 zip으로 압축
2. PocketRisu의 설정 > 데이터 이전 > "노드리스에서 save 폴더 가져오기" 아코디언 열기
3. "Save 폴더에서 불러오기 (Zip 업로드)"로 zip 파일 업로드

> 압축 파일 용량이 클 경우 업로드가 실패할 수 있습니다. 이 경우 [4. Save 폴더 직접 복사](#4-save-폴더-직접-복사)를 사용하세요.


---

## 4. Save 폴더 직접 복사

대용량 데이터(수 GB 이상)에 적합한 방식입니다. 서버 파일 시스템에 직접 접근할 수 있어야 합니다.

1. PocketRisu 서버 정지
2. 기존 RisuAI의 `save` 폴더를 PocketRisu의 `save` 폴더에 통째로 덮어쓰기
3. PocketRisu 서버 재시작 — 자동 마이그레이션이 진행됩니다
    - 터미널 또는 PM2 로그에서 진행률을 확인할 수 있습니다
4. 마이그레이션 완료 후, 설정 > 데이터 이전 > "노드리스에서 save 폴더 가져오기" 아코디언의 "마이그레이션된 Save 파일 정리"로 원본 파일을 제거해 디스크 공간을 회수

## 어떤 방법을 선택해야 하나요?

| 상황                                       | 권장 방법                |
| ------------------------------------------ | ------------------------ |
| 웹 리스에서 이전                           | 2. `.bin` 백업           |
| 웹 리스에서 이전, 백업이 암호화되어 거부됨 | 1. RisuAI 계정에서 가져오기 |
| 로컬 리스에서 이전, 데이터 소규모          | 3. zip 업로드            |
| 로컬 리스에서 이전, 데이터 대규모(10GB+)   | 4. Save 폴더 직접 복사   |
| 판단이 어려움                              | 2. `.bin` 백업           |
